# Security Policy

## Supported Versions
| Version | Supported |
|---------|-----------|
| 1.x (production) | ✅ |

## Reporting a Vulnerability
Please report security vulnerabilities by opening a GitHub Security Advisory at:
https://github.com/Adri1506/Chambecas/security/advisories

Do NOT open public issues for security vulnerabilities.

## Security Measures
- HTTPS enforced via Vercel
- No sensitive data stored in the repository
- Form submissions handled by Formspree (third-party)
- No backend, database, or authentication exposed
- Content Security Policy recommended for production
